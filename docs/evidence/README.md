**Status key:**
- **SOURCED:** shown in a reference image, or reported as an observation in the GBFans thread.
- **MEASURED:** measured frame by frame from the deleted-scene clip (V1).
- **ESTIMATE:** the text and order are sourced, but this detail is a best guess.
- **INFERRED:** reconstructed from partial evidence; each card separates the sourced and inferred parts.
